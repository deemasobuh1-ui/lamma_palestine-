# Lamma | لَمّة 🇵🇸

A Palestinian platform for discovering creative workshops and experiences across Palestinian cities.

## About the Project
لَمّة هو موقع يتيح للمستخدمين اكتشاف الورش والتجارب الإبداعية في المدن الفلسطينية، واختيار المدينة ونوع النشاط المناسب لهم.

## Main Features
- Explore workshops by city.
- Filter workshops by category.
- View workshop details.
- Register for available workshops.
